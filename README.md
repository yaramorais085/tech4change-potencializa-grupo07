# Projeto Potencializa
## Adaptação de Avaliações com Inteligência Artificial

### 📖 Descrição da solução
O **Projeto Potencializa** tem como objetivo apoiar professores na redução do tempo gasto em tarefas administrativas, começando pela **adaptação de avaliações para alunos com diferentes necessidades**.  
A solução utiliza Inteligência Artificial para gerar versões adaptadas de provas, acompanhadas de justificativas pedagógicas, sem substituir a prática docente.
